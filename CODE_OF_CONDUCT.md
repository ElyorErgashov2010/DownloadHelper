# Code of Conduct / Xulq-atvor qoidalari

## Our commitment / Bizning majburiyatimiz

We want DownloadHelper to be a welcoming, respectful, and useful project for
all users and contributors. Harassment, insults, threats, discrimination,
spam, deceptive activity, or intentionally harmful contributions are not
accepted.

DownloadHelper barcha foydalanuvchi va hissa qo'shuvchilar uchun hurmatli,
foydali loyiha bo'lishini istaydi. Haqorat, tahdid, kamsitish, spam, aldovchi
faollik yoki ataylab zarar yetkazadigan o'zgartirishlar qabul qilinmaydi.

## Expected behavior / Kutiladigan xulq

- Be respectful and constructive / Hurmatli va foydali fikr bildiring.
- Report bugs honestly and include reproducible details / Xatolarni rost yozing
  va qayta takrorlash mumkin bo'lgan ma'lumot bering.
- Respect privacy and never publish credentials, private links, or personal data
  / Maxfiylikni hurmat qiling; kalit, maxfiy havola va shaxsiy ma'lumotni
  e'lon qilmang.
- Do not manipulate Stars, Issues, Pull Requests, reviews, downloads, or other
  community signals / Star, Issue, Pull Request, review, download va boshqa
  faollik signallarini sun'iy ravishda oshirmang.

## Scope / Amal qilish doirasi

These rules apply to GitHub Issues, Pull Requests, Discussions, documentation,
and any project-related public communication.

Bu qoidalar GitHub Issue, Pull Request, Discussion, hujjatlar va loyiha bilan
bog'liq ochiq muloqotlarga amal qiladi.

## Reporting / Xabar berish

For a conduct concern, contact the maintainer through the GitHub profile or a
private communication channel. Do not start a public argument containing
personal information.

Xulq-atvor bilan bog'liq muammo bo'lsa, maintainer bilan GitHub profili yoki
xususiy muloqot kanali orqali bog'laning. Shaxsiy ma'lumotlar bilan ochiq
bahs boshlamang.
