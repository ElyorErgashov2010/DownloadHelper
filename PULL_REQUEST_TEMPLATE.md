## O'zgarish mazmuni

Qanday o'zgarish kiritildi va nima uchun kerakligini yozing.

## Tekshiruv

- [ ] O'zgarish mahalliy yoki GitHub Actions test build orqali tekshirildi.
- [ ] README/Yordam/Changelog kerak bo'lsa yangilandi.
- [ ] Maxfiy ma'lumot, token, parol yoki private URL qo'shilmadi.
- [ ] Build, release yoki code-signing workflow o'zgargan bo'lsa alohida tushuntirildi.

## Bog'liq Issue

`Fixes #...` yoki `Resolves #...` deb yozing. Agar Issue bo'lmasa sababini yozing.
