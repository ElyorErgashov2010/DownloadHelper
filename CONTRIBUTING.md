# Hissa qo'shish va fikr bildirish

DownloadHelper'dan foydalansangiz, real fikr, xato xabari va takliflar
loyihani yaxshilashga yordam beradi.

## Xato haqida xabar berish

GitHub'da [New issue](https://github.com/ElyorErgashov2010/DownloadHelper/issues/new)
tugmasini bosing va quyidagilarni yozing:

1. Qanday amal bajardingiz.
2. Nima bo'lishini kutgandingiz.
3. Aslida qanday xato bo'ldi.
4. Windows versiyasi va DownloadHelper release versiyasi.
5. Mumkin bo'lsa screenshot yoki logdan xato qatori.

> **Maxfiy ma'lumot yubormang:** S3 access key/secret key, login, token,
> shaxsiy video URL yoki media decryption key'ni issue, screenshot yoki logga
> qo'shmang.

## Yangi taklif yuborish

[New issue](https://github.com/ElyorErgashov2010/DownloadHelper/issues/new)
orasidan taklif yozing. Unda:

- muammo yoki ehtiyojni;
- kim uchun foydali ekanini;
- kerakli natijani;
- imkon bo'lsa interfeys namunasi/screenshotni yozing.

## Kod bilan hissa qo'shish

Kodga o'zgartirish kiritmoqchi bo'lganlar pull request yuborishdan oldin
repository'dagi mavjud o'zgarishlar va issue'larni ko'rib chiqishi kerak.
Xavfsizlikka ta'sir qiladigan, build/release yoki code-signing workflow'ini
o'zgartiradigan pull request'lar alohida sinchiklab tekshiriladi.

## Loyihani qo'llab-quvvatlash

Agar dastur sizga foydali bo'lsa, GitHub'da **Star** bosing yoki haqiqiy
foydalanish tajribangiz haqida Issue/Discussion orqali fikr qoldiring.
Sun'iy yoki sotib olingan stars/reviews ishlatilmaydi.
